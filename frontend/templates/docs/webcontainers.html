How Your Sandbox Works

Every project gets a real, isolated cloud environment — not a mock, not a simulation.

The Legacy Cloud Trap

Most AI coding platforms use one of two broken models to run your code:

  1. Static Only: They only generate HTML/CSS/React and mock the data, leaving you stranded when you actually need a database or user authentication.
  2. Slow Cloud Compute: They spin up a fresh, cold Docker container for every request, which introduces massive latency every time the agent needs to run a command.

The Gor://a Solution: Live Sandboxes

Every project you build runs inside its own isolated cloud sandbox — a real Linux environment with a real Node.js runtime, real file system, and a real terminal. The agent writes files, runs npm install, and starts your dev server exactly like a developer would on their own machine, just orchestrated remotely instead of on your device.

The Boot Sequence

When the agent finishes planning your app, it takes over the sandbox:

  1. Provisioning: A dedicated sandbox spins up and your project's files are synced into it.
  2. Dependency Resolution (npm install): It scans the package.json the AI generated and installs dependencies inside the sandbox.
  3. The Dev Server (npm run dev): It boots up Vite and Express, and verifies both are actually responding before moving on.
  4. Live Preview: The sandbox exposes a live URL that streams straight into the Editor's preview pane.

Isolation: Every project's sandbox is fully separated from every other project and from Gor://a's own infrastructure. File operations are strictly confined to your project's own directory — the agent can't read or touch anything outside it.

Why This Matters

Because your app runs in a real environment instead of a browser-side simulation, you get real npm packages, a real filesystem, and real command execution — the same thing you'd get running the project locally, minus the setup. That's also what makes the auto-healing loop possible: the agent can see the dev server's actual logs and actual exit codes, not an approximation of them.
